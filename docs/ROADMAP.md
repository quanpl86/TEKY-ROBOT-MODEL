# TEKY Rover Roadmap

**Phase 0 — Foundation**: repository roles, manifests, asset index, repo instructions; canonical baseline reset to 4 rubber 2WD and no attachment/LiDAR/laser. Separate Guard, Sensor Packs, Drive Systems, nine historical attachments.

**Phase 1 — Mechanically credible family**: verify four chassis-compatible tire/transmission types; refine rubber front passive hub without scaled tire distortion; correct all wheel/guard/chain clearance; exact dock mating surfaces and sensor pillars. Camera mast optional, removable.

**Phase 2 — TEKY adapter**: inspect native TEKY source/schema; implement GLB visual-node binding and hide only native display; map 2 motors, 3 color sensors, ultrasonic and optional advanced sensors. Separate collider bodies, fixed joints, chain transmission and joints. Use test world 20mm line, 40mm blocks, 200mm shelf.

**Phase 3 — Nine attachment acceptance**: each module with hierarchy, true pivot, source, part GLBs, motion ranges, five+ poses, stress cases, physics, payload and visual QA. Fix bucket ultrasonic occlusion, forklift travel, sweeper swing, launcher feed.

**Phase 4 — Intelligence**: road sign color/shape recognition, calibrated top camera view, combined line-follow vision + color readers, obstacle avoidance and camera/LiDAR occlusion map. AI perception optionally enabled, respect education safety/privacy.

**Phase 5 — Premium & production**: procedural low-poly master, high quality PBR visual, thumbnail views, multi-robot runtime profile, CI validation, versioned stable release.

For each phase: owner, issue/PR, version, exact GLB SHA256, known limitations and acceptance tests. No unverified runtime claims.
